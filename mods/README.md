# Mods

Mods people made with [MCSuperMods](https://github.com/MEZTKING/MCSuperMods) and shared here. Each folder is a project: open it in MCSuperMods with **File > Open Project…** and pick the folder with `msm.project.json` in it. Each mod's README says who made it, what it adds, how to play it and its licence.

Want to add yours? Copy your project into `mods/<your-mod-name>/` with a README from [the template](_template/README.md), a `picture.png` and a `LICENSE`, and open a pull request. [CONTRIBUTING.md](../CONTRIBUTING.md) explains each step.
