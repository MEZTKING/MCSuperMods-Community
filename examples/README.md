# Examples

The 87 example projects that ship with MCSuperMods, each a folder you can open in the app (**File > Open Project…**). Each folder has a README with a picture, what the example shows and how to open it.

These folders are made from the MCSuperMods `examples/` folder by `tools/community-repo/sync.ts`; do not change them by hand. Share your own mods in [`mods/`](../mods/).
